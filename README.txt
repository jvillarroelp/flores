# 🌻 Flores para Bebé

Pequeña página romántica interactiva hecha con HTML, CSS y JavaScript.

## Archivos

- `index.html` — estructura de la página.
- `style.css` — diseño, animaciones y responsive.
- `script.js` — preguntas, transición y pétalos.

## Cómo probarla

Abre `index.html` con doble clic.

## Cómo subirla gratis con GitHub Pages

1. Crea un repositorio público en GitHub, por ejemplo:
   `flores-para-bebe`
2. Sube `index.html`, `style.css` y `script.js`.
3. En el repositorio entra a:
   **Settings → Pages**
4. En "Build and deployment" selecciona:
   **Deploy from a branch**
5. Selecciona la rama `main` y carpeta `/ (root)`.
6. Guarda.
7. GitHub generará una dirección parecida a:
   `https://TUUSUARIO.github.io/flores-para-bebe/`

No necesitas servidor, base de datos ni instalar nada en el computador de ella.

## Personalización rápida

Todo el contenido romántico está en `index.html`. Puedes cambiar:

- "Bebé"
- "mi niña hermosa"
- el mensaje final
- "tu niño" por tu nombre o apodo

Las preguntas y respuestas también están en `index.html`.
